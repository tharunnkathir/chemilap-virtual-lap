
# 🧪 ChemiLab - Cheminformatics Virtual Laboratory

Welcome to ChemiLab!

ChemiLab is an interactive virtual chemistry laboratory developed using Python and Streamlit.

## Features

- Chemical Compound Explorer
- Molecular Weight Calculator
- Molecular Structure Viewer
- Element Composition Analysis
- Functional Group Identification
- Compound Comparison
- Chemistry Quiz
- PDF Report Generation

## Technologies Used

- Python
- Streamlit
- RDKit
- Pandas
- Plotly
- ReportLab

## Installation

Install the required libraries:

pip install -r requirements.txt

## Run Application

streamlit run app.py

## Project Objective

The objective of ChemiLab is to provide students with an interactive platform to explore chemical compounds, understand molecular structures and calculate molecular properties.

## Developed For

Academic Virtual Chemistry Laboratory Project.
